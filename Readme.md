# Запуск
Войдите в Nix-окружение проекта:
```bash
nix develop
```
Запустите сервер MySQL в фоновом режиме:
```bash
start-mysql
```
Запустите скрипт автоматического сбора дампов таблиц:
```bash
run-bench
run-entropy
```
По завершении тестов остановите службу СУБД:
```bash
stop-mysql
```
# Результат
Все файлы в директории ./mysql_bench_blocks/ разбиты на строгие 16-килобайтные куски (16384 байта).

# Специфика тестирования алгоритма дедупликации на MySQL:
- Эффект нативного JSON (mysql_4_json.ibd.raw): В отличие от MariaDB, оригинальный MySQL переводит тип данных JSON в собственный оптимизированный бинарный формат перед записью в строку (структурированные бинарные деревья ключей/значений).
